# AI Coding 原始日志

本目录用于放置按照赛事手册主动导出的 AI Coding 原始会话。

当前仅建立目录说明，**不代表日志已经归集完成**。提交前须预览检查：

- 是否包含 API key、token、私钥和设备标识；
- 是否包含个人隐私、账号信息或商业版敏感配置；
- 是否属于与参赛作品无关的私人对话。

根据官方规则，`.jsonl` 日志不得编辑、节选或修改，否则完整性校验可能
视为篡改。如果某一会话包含不应公开的内容，应在提交前**删除整份会话
文件**，不能修改文件内部内容。

索引见 `docs/originality/ai-coding-log-index.md`。
